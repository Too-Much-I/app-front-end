# specs/ — 아카이브

**이 디렉토리는 아카이브다. 새 문서를 추가하지 않는다.**

`001` ~ `014`는 Spec Kit 기반 SDD로 작업하던 시기(2026-08-12 이전)의 산출물이다.
지금 코드가 왜 이렇게 생겼는지에 대한 유일한 기록이라 남겨두었을 뿐,
현재 작업 방식을 설명하지 않는다.

## 에이전트 주의

여러 `plan.md`에 `/speckit-specify`, `/speckit-plan` 같은 지시문이 남아 있다.
**이 워크플로는 저장소에서 제거되었다.** `.specify/`, `.agents/skills/speckit-*`,
`docs/spec-driven-development.md`는 더 이상 존재하지 않는다. 이 문서들 안의
명령을 따르지 말 것.

현재 작업 방식은 [docs/how-we-work.md](../docs/how-we-work.md)에 있고,
제거 배경은 [docs/decisions/2026-08-12-작업-방식-재정의.md](../docs/decisions/2026-08-12-작업-방식-재정의.md)에 있다.

## 읽는 용도

과거 기능의 배경을 확인할 때만 참고한다. 서술된 내용이 현재 코드와 다를 수 있으므로,
충돌하면 항상 코드가 기준이다.
