## Clarifications

### Session 2026-08-03

- Q: 만점이 다른 재답변 문제들의 평균 개선을 어떤 단위로 표시하는가? → A: 문제별 최초·최신 답변의 `점수/만점` 달성률 차이를 구한 뒤 평균하여 퍼센트포인트(%p)로 표시한다. 100점 환산 점수는 만들지 않는다.

## Scope *(mandatory)*

### In Scope

- 피드백 기록 화면을 `모의고사 기록`과 `다시 답변한 문제` 두 탭으로 구분한다.
- 모의고사 기록 탭에서 여러 모의고사의 평균 점수 추이와 개별 시험 기록을 제공한다.
- 개별 모의고사 기록의 등급 배지는 등급에 따라 일관된 색을 사용하되 등급 문자를 함께 표시한다.
- 다시 답변한 문제 탭에서 완료된 재답변이 있으면 최초 답변 대비 평균 달성률 변화와 향상한 문제 수를 요약한다.
- 재답변 성과 요약에는 제공된 차트 일러스트를 장식 요소로 사용한다.
- 완료된 재답변이 없으면 재답변을 유도하는 안내와 선택 가능한 행동을 제공한다.
- 빈 상태의 안내를 선택하면 가장 최근 완료 모의고사의 전체 피드백 중 파트별 피드백 단계(현재 화면 계약의 `state=3`)를 연다.
- 재답변 기록의 로딩, 조회 실패, 비교 불가능한 점수와 채점 대기 상태를 빈 상태와 구분한다.
- 휴대폰과 태블릿, 큰 글자 설정, 색각 차이와 보조 기술을 고려한다.

### Out of Scope

- 서로 다른 문제의 절대 점수를 하나의 연속된 점수 추이로 연결하는 그래프
- 재답변 점수 또는 등급을 새로 산정하는 채점 정책
- 재답변 성과 배너를 통한 문제 상세 이동 또는 별도의 성장 리포트 화면
- 재답변 기록이 있을 때 성과 배너에 누르기 동작을 제공하는 것
- 문제별 피드백, 재답변 녹음과 제출 화면 자체의 재설계
- 과거에 저장되지 않은 시험 또는 재답변 기록의 소급 생성
- 등급 색만으로 등급이나 성과를 전달하는 표현

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 모의고사 기록과 등급 확인 (Priority: P1)

학습자는 모의고사 기록 탭에서 평균 점수의 변화와 각 시험의 점수·등급을 빠르게 확인한다.

**Why this priority**: 전체 시험 성과를 시간 순서로 이해하는 기존 기록 화면의 핵심 목적이며 두 탭 구조의 기준이 되기 때문이다.

**Independent Test**: 서로 다른 날짜와 등급을 가진 모의고사 기록을 열어 평균 점수 추이와 모든 개별 기록의 점수·등급이 올바르게 표시되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 완료된 모의고사가 여러 개 있을 때, **When** 피드백 기록 화면을 열면, **Then** `모의고사 기록` 탭이 기본으로 선택되고 평균 점수 추이와 개별 기록이 함께 표시된다.
2. **Given** 개별 기록의 등급이 서로 다를 때, **When** 기록 목록을 확인하면, **Then** 각 등급 배지는 해당 등급에 정해진 색과 읽을 수 있는 등급 문자를 함께 표시한다.
3. **Given** 큰 글자 또는 색각 차이가 있는 사용자가 기록을 확인할 때, **When** 배지를 탐색하면, **Then** 색을 구분하지 않아도 등급 문자를 통해 동일한 정보를 알 수 있다.

### User Story 2 - 재답변 성과 확인 (Priority: P1)

재답변을 완료한 학습자는 서로 다른 문제의 절대 점수를 억지로 비교하지 않고, 최초 답변보다 평균적으로 얼마나 좋아졌고 몇 문제가 향상됐는지 확인한다.

**Why this priority**: 재답변 행동의 효과를 오해 없이 전달하는 것이 새 탭의 핵심 사용자 가치이기 때문이다.

**Independent Test**: 최초 답변과 최신 재답변 점수가 있는 여러 문제를 준비하고 평균 달성률 변화, 향상 문제 수와 전체 비교 문제 수가 계산 결과와 일치하는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 비교 가능한 재답변 문제가 8개이고 그중 6개의 최신 점수가 최초 점수보다 높을 때, **When** `다시 답변한 문제` 탭을 열면, **Then** 배너에 평균 달성률 변화와 `6/8문제 향상`이 표시된다.
2. **Given** 같은 문제를 여러 번 다시 답했을 때, **When** 성과가 계산되면, **Then** 해당 문제는 한 번만 집계되고 최초 답변과 최신 완료 답변이 비교된다.
3. **Given** 재답변 성과 배너가 표시될 때, **When** 사용자가 배너를 보조 기술 또는 터치로 탐색하면, **Then** 배너는 누를 수 있는 요소로 안내되거나 동작하지 않고 성과 정보만 제공한다.
4. **Given** 문제의 만점이 정해져 있을 때, **When** 최초 답변과 최신 답변을 비교하면, **Then** 각 답변의 `점수/만점` 달성률 차이가 계산되고 100점 환산 점수는 만들어지지 않는다.

### User Story 3 - 첫 재답변 시작 (Priority: P1)

아직 재답변한 문제가 없는 학습자는 빈 화면 대신 재답변의 가치를 이해하고, 가장 최근 시험의 파트별 피드백으로 이동해 다시 답할 문제를 고를 수 있다.

**Why this priority**: 데이터가 없는 상태를 다음 학습 행동으로 연결해 새 기능을 시작할 수 있게 하기 때문이다.

**Independent Test**: 완료된 모의고사는 있지만 완료된 재답변은 없는 계정으로 빈 상태 배너를 선택해 최근 시험의 파트별 피드백 단계가 열리는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 완료된 재답변 문제가 없을 때, **When** `다시 답변한 문제` 탭을 열면, **Then** 차트 일러스트와 `재답변을 하고 나의 변화를 확인해 보세요` 의미의 안내가 표시된다.
2. **Given** 빈 상태 안내가 표시될 때, **When** 사용자가 안내를 선택하면, **Then** 가장 최근 완료 모의고사의 전체 피드백에서 파트별 피드백 단계가 열린다.
3. **Given** 빈 상태 안내가 선택 가능할 때, **When** 보조 기술로 탐색하면, **Then** 이동 목적과 선택 가능 여부를 명확히 알 수 있다.

### Edge Cases

- 재답변 기록을 불러오는 중에는 성과값이나 빈 상태 행동을 미리 표시하지 않는다.
- 재답변 기록 조회가 실패하면 재답변이 없다고 안내하지 않고 실패 상태와 복구 동작을 제공한다.
- 재답변 제출은 완료됐지만 채점이 끝나지 않은 문제는 완료 성과 집계에서 제외하고 대기 상태로 구분한다.
- 최초 또는 최신 답변의 점수나 만점이 없거나 유효하지 않으면 해당 문제를 비교 집계에서 제외하고 비교 가능한 문제 수에 포함하지 않는다.
- 비교 가능한 재답변 문제는 있지만 평균 달성률 변화가 0%p이거나 음수인 경우에도 부호와 실제 향상 문제 수를 그대로 표시하고 성공으로 과장하지 않는다.
- 완료된 재답변은 없지만 채점 대기 중인 재답변이 있으면 첫 재답변 유도 행동 대신 채점 대기 사실을 알린다.
- 완료된 모의고사도 없으면 파트별 피드백을 열 수 없으므로 모의고사 시작 안내를 제공한다.
- 가장 최근 완료 모의고사가 삭제되거나 접근할 수 없으면 잘못된 피드백을 열지 않고 기록을 다시 확인할 수 있는 복구 안내를 제공한다.
- 긴 등급명, 큰 글자 설정과 좁은 화면에서도 배지, 점수, 배너 문구와 일러스트가 겹치거나 잘리지 않는다.
- 같은 등급은 화면과 방문 시점에 관계없이 항상 같은 색으로 표시된다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 피드백 기록 화면은 `모의고사 기록`과 `다시 답변한 문제` 두 탭을 제공해야 한다.
- **FR-002**: 피드백 기록 화면의 기본 선택은 `모의고사 기록`이어야 한다.
- **FR-003**: 모의고사 기록 탭은 완료된 시험의 평균 점수 추이와 날짜별 개별 기록을 표시해야 한다.
- **FR-004**: 각 모의고사 기록은 점수와 등급 문자를 표시해야 한다.
- **FR-005**: 동일한 등급은 항상 동일한 배지 색을 사용해야 하며 색은 배지 범위에 한정되어야 한다.
- **FR-006**: 등급 배지는 색상 없이도 등급을 식별할 수 있는 문자 정보를 제공해야 한다.
- **FR-007**: 다시 답변한 문제 탭은 완료된 재답변 기록의 존재 여부에 따라 성과 상태와 시작 유도 상태를 구분해야 한다.
- **FR-008**: 비교 가능한 재답변 기록이 있으면 성과 배너는 평균 달성률 변화와 `향상한 문제 수/비교 가능한 전체 문제 수`를 표시해야 한다.
- **FR-009**: 문제별 개선 여부는 최초 답변과 최신 완료 재답변의 원점수를 해당 문제의 만점과 함께 비교해 판단해야 하며, 점수를 100점 기준으로 환산해서는 안 된다.
- **FR-010**: 각 문제의 달성률 변화는 `(최신 완료 답변 점수/문제 만점) - (최초 답변 점수/문제 만점)`으로 계산해야 한다.
- **FR-011**: 평균 달성률 변화는 비교 가능한 고유 문제들의 달성률 변화를 산술 평균하고 퍼센트포인트(%p) 단위로 표시해야 한다.
- **FR-012**: 향상한 문제는 최신 완료 답변의 원점수가 최초 답변의 원점수보다 높은 고유 문제로 정의해야 한다.
- **FR-013**: 같은 문제에 완료된 재답변이 여러 개 있어도 성과 집계에서는 한 문제로 계산해야 한다.
- **FR-014**: 완료된 재답변 기록이 있는 성과 배너는 선택 동작이나 선택 가능해 보이는 표현을 제공해서는 안 된다.
- **FR-015**: 완료된 재답변 기록이 없으면 차트 일러스트, 재답변 가치 안내와 파트별 피드백으로 이동하는 선택 동작을 제공해야 한다.
- **FR-016**: 빈 상태 선택은 가장 최근 완료 모의고사의 전체 피드백 중 파트별 피드백 단계(현재 계약의 `state=3`)를 열어야 한다.
- **FR-017**: 완료된 모의고사가 없는 경우에는 실행할 수 없는 파트별 피드백 이동을 제공하지 않고 모의고사 시작 안내를 제공해야 한다.
- **FR-018**: 로딩, 조회 실패, 채점 대기, 비교 불가능과 실제 빈 상태를 서로 구분해야 한다.
- **FR-019**: 조회 실패 상태는 사용자가 기록을 다시 불러올 수 있는 복구 동작을 제공해야 한다.
- **FR-020**: 성과 배너와 빈 상태 안내는 동일한 차트 일러스트를 사용할 수 있지만, 선택 가능 여부를 문구와 접근성 정보로 명확히 구분해야 한다.
- **FR-021**: 성과 배너는 등급에 따라 색이 바뀌지 않고 일관된 브랜드 표현을 유지해야 한다.
- **FR-022**: 탭, 기록, 배지, 배너와 모든 선택 동작은 휴대폰·태블릿·큰 글자 설정과 보조 기술에서 내용이 잘리거나 의미가 사라지지 않아야 한다.

### Key Entities

- **모의고사 기록**: 완료 날짜, 전체 점수, 평균 점수 산정 대상과 등급을 가진 한 번의 완료 시험
- **등급 표현**: 등급 문자와 해당 등급에 일관되게 연결된 배지 색의 조합
- **재답변 문제 기록**: 시험과 문제를 식별하고 최초 답변, 하나 이상의 재답변 회차 및 각 회차의 채점 완료 상태를 연결하는 기록
- **비교 가능한 재답변 문제**: 최초 답변과 최신 완료 재답변 모두 유효한 점수와 점수 기준을 가진 고유 문제
- **재답변 성과 요약**: 비교 가능한 문제 수, 향상한 문제 수와 고유 문제들의 평균 달성률 변화
- **재답변 시작 대상**: 완료된 재답변이 없을 때 파트별 피드백 단계로 이동할 가장 최근 완료 모의고사

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자는 피드백 기록 화면에서 한 번의 선택으로 모의고사 기록과 다시 답변한 문제 사이를 전환할 수 있다.
- **SC-002**: 완료된 모의고사 샘플의 100%에서 추이 점수, 개별 점수와 등급이 원본 기록과 일치한다.
- **SC-003**: 같은 등급이 서로 다른 색으로 표시되거나 색만으로 등급을 전달하는 검증 사례가 0건이다.
- **SC-004**: 재답변 성과 샘플의 100%에서 평균 달성률 변화(%p), 향상한 문제 수와 비교 가능한 전체 문제 수가 정의된 계산 결과와 일치한다.
- **SC-005**: 동일 문제의 여러 재답변 회차가 성과의 문제 수를 중복 증가시키는 사례가 0건이다.
- **SC-006**: 재답변 기록이 있는 경우 성과 배너에서 선택 동작이 실행되거나 선택 가능한 요소로 안내되는 사례가 0건이다.
- **SC-007**: 완료된 재답변이 없는 사용자는 빈 상태 안내를 한 번 선택해 가장 최근 시험의 파트별 피드백에 도달할 수 있다.
- **SC-008**: 로딩 또는 조회 실패를 실제 재답변 없음으로 표시하는 검증 사례가 0건이다.
- **SC-009**: 지원되는 휴대폰·태블릿과 큰 글자 설정 검증에서 탭, 배지, 배너 문구와 일러스트가 겹치거나 잘리는 사례가 0건이다.

## Assumptions

- `TMI-44`는 현재 브랜치의 피드백 기록 및 재답변 성과 요약 작업을 식별한다.
- 모의고사 기록 탭의 평균 점수 추이는 서로 비교 가능한 전체 시험 점수를 시간 순서로 보여준다.
- 최근 완료 모의고사는 완료 시각이 가장 늦고 사용자가 접근할 수 있는 시험을 의미한다.
- 재답변 성과에는 채점이 완료된 회차만 사용한다.
- 문제별 비교는 서버가 제공하는 원점수와 해당 문제의 만점을 그대로 사용하며 100점 환산 점수를 만들지 않는다.
- 평균 달성률 변화는 소수점 첫째 자리까지 반올림해 `+12.4%p`처럼 부호와 단위를 함께 표시한다.
- 등급별 구체적인 색상 값과 등급 구간 묶음은 접근성 대비와 기존 디자인 체계를 검토하는 계획 단계에서 확정한다.
- 차트 일러스트는 성과값 자체를 표현하는 실제 그래프가 아니라 배너의 의미를 보조하는 장식 이미지다.
