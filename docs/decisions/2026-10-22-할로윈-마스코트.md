# 할로윈 마스코트

## 문제

3.0.2에 iOS 대체 아이콘(할로윈)을 넣었지만, 아이콘 A/B 테스트에서 기본 아이콘을 받은 사용자나 Android 사용자는
할로윈 분위기를 볼 수 없다. 앱에 들어왔을 때 한동안 할로윈 그림이 보이게 하려 한다.

앱에 `expo-updates`가 없어 그림을 바꾸려면 새 빌드가 필요하다. 할로윈이 지난 뒤 원래대로 돌리는 것도 마찬가지다.

## 선택지

| 안 | 방식 | 비용 |
| --- | --- | --- |
| A. 날짜로 기간 | 정한 시각 전까지만 할로윈 그림, 지나면 자동으로 원래 그림 | 날짜가 코드에 박힘, 기기 시각 기준 |
| B. 그냥 교체 | 그림 파일만 바꿈 | 되돌리려면 빌드·심사를 다시 거침 |
| C. 서버 값 | 서버가 켜고 끔 | 서버 작업 필요, 이번 일정에 못 맞춤 |

## 결정

B. 스플래시는 어차피 되돌리는 빌드가 필요하므로, 홈 그림도 날짜 조건 없이 교체하고 할로윈이 끝나면 다음 빌드에서
함께 원래대로 돌린다. 3.0.2를 새 빌드로 낸다(이미 올린 빌드 16은 심사에 내지 않는다).

- 홈 인사 토끼 자리: 호박 토끼 bust.
- 홈 최근 피드백 카드 토끼 자리: 바구니 든 유령 토끼 전신(bust 아님).
- 받은 그림은 흰 배경이라 배경을 투명하게 따서 쓴다.
- 스플래시 로고도 iOS 대체 아이콘과 같은 할로윈 그림으로 바꾼다. 아이콘 파일은 모서리까지 꽉 찬 정사각형이라 흰 배경에서
  각진 네모로 보이므로, 받은 둥근 모서리 원본의 검은 바깥을 투명하게 따서 쓴다.
- 로그인 화면 인사 토끼 자리: 드라큘라 토끼 전신.
- 서비스명 옆 작은 로고(`public/logo.png`)를 쓰는 곳(홈 상단, 로그인 화면)을 마녀 모자 로고 `logo_halloween.png`로 바꾼다.
- iOS·Android 모두 같은 JS 번들이라 두 플랫폼에 같이 보인다.

## 하지 않은 것

- 날짜로 기간 정하기(A), 서버로 켜고 끄기(C).
- 자동 복귀. 다음 출시 빌드에서 홈 그림과 스플래시를 원래대로 돌린다.
- 홈·로그인 화면 밖의 마스코트 교체.

## 되돌림 (2026-10-31)

3.2.0 재빌드에서 홈 인사·최근 피드백 토끼, 서비스명 로고, 스플래시를 할로윈 전으로 되돌리고 할로윈 그림 파일을 지웠다.
로그인 화면은 드라큘라 토끼 자리에 헤드셋 토끼(`headset_rabbit.png`)를 넣고 "Happy Halloween!" 문구를 뺐다.
iOS 대체 아이콘(#97)은 아이콘 A/B 테스트가 끝나지 않아 남겨 두고 나중에 정리한다.
