# 예상 3줄 대신 설계 논의 기록

## 문제

3단계 "구현 전 예상 3줄"([도입 결정](2026-09-30-뼈대-대신-구현-전-예상.md))은 AI의 답을 보기 전에
생각을 먼저 만들려는 장치였다. Guest 승격 설계(2026-10-01)에서 1·2단계 논의가 길어지자 두 가지가 드러났다.

- AI의 답(업계 관행, 실패 시나리오, 5xx 분류, 판별 흐름)이 이미 설계 논의 중에 나왔다. 정답지를 먼저
  보는 일은 3단계가 아니라 1·2단계에서 일어났다.
- 그 뒤에 쓰는 예상은 설계를 다시 옮겨 적는 것이 된다. 정작 값진 기록인 판단이 바뀐 지점(예: "학습
  기록을 잃을 수밖에 없다" → 병합으로 보존됨)은 대화 속에서만 정정되고 어디에도 남지 않았다.

사용자 문제 제기(원문): "우리가 설계 단계에서 논의한 내용이 되게 많은데 예상에서는 그냥 정상 구현 흐름
하나에 대한 예상과 그렇게 동작할 거라는 이유와 반증을 쓰면 되는 거야? 근데 또 이상한게 저게 설계와
다를게 없잖아"

## 선택지

| 안 | 이점 | 비용 |
| --- | --- | --- |
| 3단계 대상을 "구현 예상"으로 재정의(구현 모양·마찰 지점·논의 안 한 상황) | 도구 변경 없음 | 1·2단계의 판단 이동은 여전히 남지 않음 |
| 예상 시점을 1단계 전으로 이동 | AI 답 전의 생각이 확실히 남음 | 설계가 긴 작업에서 3단계가 중복 |
| 설계 논의 기록으로 대체 | 판단이 움직인 지점이 남음 | AI가 정리하므로 "AI 전 생각"이 흐려질 위험, 도구·문서 변경 |
| 지금처럼 유지 | 변경 없음 | 설계와 같은 내용을 반복 |

## 결정

사용자 결정(원문): "설계를 하는 단계에서의 티키타카를 정리하는게 좋을까? 어떤 부분을 고려하고 어떤 실패
사례까지만 생각하기로 했으며 실제로 비교해본 대안이나 그걸 채택한 이유나 이런 것? 질문을 하고 그에 대한
답을 하는 방식이더라도 어쩃든 나의 판단이나 예상이 선행되고 있으니까 그리고 이 과정에서 ai가 먼저 답을
제시하지 말고 한번의 제안이 있은 후부터 논의가 있는 걸로 해서 내 생각의 틀을 한정하지 않는 방향으로
지금의 논의가 일어나게 하고 기록은 해당 세션 내에서의 대화를 총합해서 작성하는 걸로"

AI가 보완을 제안하고 사용자가 받아들인 것:

- 쟁점마다 처음 판단 → 바뀐 계기 → 최종으로 나눠 "AI 전 판단"을 보존한다. 사람 판단은 원문 인용, AI 발언은 "AI 제안".
- 결정 기록과 나눈다: 결정 기록은 무엇을 정했나, 설계 논의는 판단이 어떻게 움직였나. 선택지 표를 옮기지 않는다.
- 반증 한 줄은 사람이 쓴다. 구현·리뷰 결과와 비교할 기준점을 남긴다.
- 사람이 AI 의견을 명시적으로 요청하면 답하고 "AI 제안"으로 남긴다.

## 코드 흐름 변화

- 학습 기록 섹션: "구현 전 예상" → "설계 논의", "예상과 달라진 것" → "설계와 달라진 것". 빈 템플릿 항목도 새 양식으로.
- `scripts/code-review/learning.mjs`: `DESIGN_SECTION`·`REQUIRED_SECTIONS`·`missingSections`로 이름 변경.
  "사람이 쓰는 섹션"이 아니게 된 설계 논의를 포함하므로 "필수 섹션"으로 부른다.
- `scripts/code-review/core.mjs`: `begin`은 설계 논의가 비어 있으면 시작하지 않고 스냅샷(`design`)을 남긴다.
  완료 보고는 `designChanged`. SessionStart 안내 문구도 바꿨다.
- `scripts/check-code-review-hooks.mjs`: 새 섹션 이름과 들여쓴 빈 템플릿을 검사한다.
- `AGENTS.md`, `docs/how-we-work.md`, `docs/learning/README.md`, `docs/code-review-cycle.md`, PR 템플릿.
- 이전 학습 기록(`구현 전 예상` 형식)은 고치지 않는다. CI는 새로 추가된 기록만 보므로 영향이 없다.

한계: `begin`은 설계 논의가 채워졌는지만 본다. 반증을 사람이 썼는지, AI가 사람 판단을 다듬지 않았는지는
검사할 수 없다. 이전 방식의 "AI가 대신 쓰지 않는다"는 장벽이 약해진다. 5단계에서 AI가 짚는 것과 사람의
확인에 맡긴다.

## 기준 충돌

예상 3줄은 AI 전 생각을 강제했고, 설계 논의 기록은 판단의 이동을 남긴다. 사용자는 1·2단계에서 AI가 답을
먼저 내지 않는 규칙으로 앞의 것을 보완하고 뒤의 것을 택했다.
