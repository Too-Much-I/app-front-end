# 학습 등급 선택 화면

## 문제

답변 익히기(학습)는 목표 등급별로 모범답안이 준비돼 있다(Part 2~5는 `IM3`·`IH`·`AL`, Part 1은 `common`).
연습에 들어가기 전에 사용자가 등급과 파트를 고르는 화면이 없다. 서버 학습 API는 아직 운영에 없고
(테스트 서버만 응답), 이 두 화면은 서버 응답 없이 정할 수 있다.

## 선택지

시안: [학습 홈 시안](https://claude.ai/artifact/DhscdAd9xawJBTt9yLUuYY).

| 주제        | 안                                                                  | 트레이드오프                                                               |
| ----------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 등급 고르기 | 탭(A) / 계단(B) / 목표 고정 타일(C) / 세트 피드(D) / 넘기는 카드(E) | 탭은 익숙하지만 전형적이다. 카드는 등급마다 다른 답을 크게 보여 줄 수 있다 |
| 화면 나누기 | 한 화면에 등급+파트 / 등급 화면 → 파트 화면                         | 한 화면은 이동이 적지만 등급 비교를 크게 보여 줄 자리가 없다               |
| 카드 디자인 | 기본 / 팔레트 칩 / 말풍선 / 퍼즐 조각 / 연습장                      | 팔레트 칩은 색 면과 캐릭터가 등급을 구분한다                               |
| 등급 이름   | IM·IH·AL / Beginner… / Basic… / Easy·Medium·Hard                    | 토익 등급은 익숙하지만 차이가 체감되지 않는다                              |
| 진입 위치   | 하단 탭 추가 / 홈 카드 / 나중에                                     | 탭은 학습을 모의고사와 같은 무게로 둔다                                    |
| 예시 문장   | 목데이터 고정 / 지어낸 문장 / 문장 없음                             | 목데이터는 등급별 차이가 작다(16문항 중 6개가 세 등급 동일)                |

## 결정

- **흐름:** 하단 탭 "학습" → ① 등급 카드 고르기 → "○○ 답변으로 연습하기" → ② 파트 고르기 → 학습 화면(지금은 빈 화면).
- **등급 카드:** 팔레트 칩 디자인. 옆으로 넘기는 카드 3장, 가운데 카드의 색으로 CTA가 바뀐다.
  - Easy: 하늘색, 가방 멘 학생 고양이(`greeting_cat`)
  - Medium: 주황, 책 위에 앉은 거북이(`study_turtle`)
  - Hard: 초록, 앉아 있는 새(`music_bird`)
- **등급 이름과 값:** 화면에는 Easy·Medium·Hard를 보여 주고, 화면 사이로 넘기는 값은 서버 파라미터 그대로
  `IM3`·`IH`·`AL`이다.
- **예시 문장:** 목데이터에서 세 등급의 답이 모두 다른 문항 하나의 답만 앱에 고정한다. 질문은 보여 주지 않고,
  제목 아래에 "트랙별로 학습하는 답변의 수준이 달라져요"라고 적는다.
- **파트 화면:** 고른 등급을 route param으로 받는다. 진행률은 서버가 없으므로 보여 주지 않는다.
- **파트를 누르면:** 등급과 파트를 받는 빈 학습 화면으로 이동한다.

## 하지 않은 것

- 서버 호출(목록·진행률·채점). `LEARNING_RATE_LIMITED`(하루 60회) 대응은 채점 단계 구현 때 다룬다.
- 고른 등급을 앱을 다시 켜도 기억하기.
- Part 1의 `common` 변환. 요청을 만드는 학습 화면에서 한다.
