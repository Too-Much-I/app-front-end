# 설정 화면 신설 및 마이페이지 제거 설계

## 배경

마이페이지 탭은 "종합 피드백 바로가기" 카드 하나만 있어 독립 탭으로 유지할 실익이 적다. 대신 홈 화면 알림 벨 옆에 설정 아이콘을 두고, 그 아이콘으로 진입하는 새 설정 화면을 만든다. 설정 화면 디자인은 `public/image.png` 목업을 따른다.

## 목업 참고 이미지

`public/image.png` — 상단에 "설정" 타이틀과 알림 벨, 마스코트 격려 카드, "학습 설정"/"서비스"/"데이터 관리" 3개 섹션. 목업 하단 탭바(홈/모의고사/피드백/학습/설정 5탭)는 참고 목적일 뿐이며, 실제로는 탭을 늘리지 않는다.

## 범위

### 포함

1. **탭 구조 변경**: `MainTabParamList`에서 `MyPage` 제거. 탭은 홈 / 모의고사 / 피드백 3개.
2. **루트 스택에 설정 화면 추가**: `RootStackParamList`에 `Settings: undefined` 추가하고 `RootNavigator`에 스택 화면으로 등록(현재 `Reanswer`처럼 탭 위에 push되는 화면).
3. **홈 화면 헤더에 설정 아이콘 추가**: 기존 알림 벨 옆에 `Feather name="settings"` 아이콘. 크기 22px, 색 `colors.ink.DEFAULT`(벨과 동일), 배지 없음. 탭 내비게이터 안에서 루트 스택 화면으로 이동해야 하므로 `FeedbackScreen`의 `CompositeNavigationProp` 패턴을 따른다.
4. **새 `SettingsScreen` 신설**: `src/screens/settings/SettingsScreen.tsx`. 목업 레이아웃을 재현하되 알림 벨은 헤더에 넣지 않고 뒤로가기 화살표로 대체(`ExamPartGuideScreen`과 동일한 헤더 패턴).
5. **기존 `MyPageScreen` 삭제**: `src/screens/my-page/` 디렉터리 전체 제거(다른 곳에서 참조 없음).

### 화면 구성 (위→아래)

- **헤더**: 뒤로가기 화살표(`navigation.goBack`) + "설정" 타이틀.
- **히어로 카드**: "토선생의 한마디" 라벨 + 격려 문구 2줄 + 보조 문구, 오른쪽에 마스코트 이미지. 새 이미지를 만들지 않고 기존 `public/mascots/greeting_rabbit.png`(오버올·나비넥타이·손 흔드는 포즈)를 재사용한다.
- **학습 설정 섹션**: 카드 안에 1행.
  - 학습 알림: 아이콘 + 제목/설명 + `Switch`(로컬 state, 기본 on). 토글은 상태만 바꾸고 영속화하지 않는다.
  - 마이크 테스트/음향 테스트 행은 만들지 않는다. 두 화면은 시험 시작 직전 흐름(자동 다음 단계 이동, 완료 시 시험 세션 생성)에 종속되어 있어 설정에서 독립적으로 쓰려면 별도 컴포넌트 설계가 필요하고, 파트 가이드를 거치면 어차피 한 번은 보게 되는 화면이라 지금 굳이 별도 진입점을 만들 실익이 없다고 판단해 범위에서 제외한다.
- **서비스 섹션**: 카드 안에 5행 — 개인정보 처리방침, 이용약관, 문의하기(설명 있음), 앱 평가하기(설명 있음), 버전 정보(우측에 `v1.0.0` 텍스트, 화살표 없음).
- **데이터 관리 섹션**: 카드 안에 1행 — 모든 학습 기록 삭제(빨간 아이콘/텍스트, 경고 설명 포함).

### 행 동작 범위 (이번 작업)

버전 정보를 제외한 모든 행(토글, 서비스 4개, 기록 삭제)은 지금 홈 화면 알림 벨과 동일하게 `TODO` 주석 + `console.log`만 남기는 스텁이다. 학습 알림 토글은 로컬 UI 상태만 바뀌고 실제 알림 권한이나 서버 저장과 연결하지 않는다.

### 스타일

- 배경/카드: 기존 토큰 재사용 — 페이지 배경 `bg-surface-subtle`, 카드 `bg-surface` + `shadows.card` + `border-line`.
- 일반 아이콘 원형 배지: 배경 `colors.brand[100]`, 아이콘 `colors.brand.DEFAULT`.
- 데이터 관리(삭제) 행만 배경 `colors.feedback.improvementSoft`, 아이콘/텍스트 `colors.feedback.improvement`.
- 아이콘 세트: `Feather`(bell, file-text, clipboard, message-circle, star, info, trash-2, chevron-right, arrow-left) — 기존 화면들이 쓰는 아이콘 패키지와 통일.
- 텍스트/터치는 공용 `Text`, `Pressable` 컴포넌트만 사용(`Switch`는 RN 기본 컴포넌트를 그대로 사용 — 공용 대체 컴포넌트 없음).

## 범위 밖 (이번 작업 제외)

- 실제 알림 권한 요청/토글 영속화.
- 마이크·음향 테스트 진입점 자체(백로그에도 남기지 않기로 확정 — 파트 가이드 흐름에서 이미 한 번 거치는 화면이라 설정 내 별도 진입점의 실익이 낮다고 판단).
- 개인정보 처리방침/이용약관/문의하기/앱 평가하기 외부 링크 또는 화면 연결.
- 학습 기록 실제 삭제 로직 및 확인 다이얼로그.
- "학습" 탭 신설(목업에는 있으나 이번 범위 아님).

## 검증

- `pnpm lint`, `pnpm exec tsc --noEmit` 통과.
- iOS 시뮬레이터 또는 Expo Go에서 홈 → 설정 아이콘 진입, 뒤로가기, 탭바가 3개로 줄었는지 육안 확인.
