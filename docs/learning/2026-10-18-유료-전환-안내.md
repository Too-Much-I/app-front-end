# 유료 전환 안내 팝업

## 설계 논의

<!-- 2026-10-18 세션 대화를 AI가 모았다. 사람의 판단은 원문 그대로, AI 발언은 "AI 제안". -->

- 쟁점: 3.0.0에서 모의고사가 유료가 되는 걸 기존 사용자에게 따로 알려야 하나
  - 처음 판단: "지금 결제를 갑자기 붙이면 사용자 반발이 생길 것 같은데 뭐 팝업이나 안내 문구를 넣었어야했나?"
  - 바뀐 계기: AI 제안 — 지금 3.0.0은 모의고사 시작 순간(준비 화면 카드, 결제 화면, 402 팝업)에야 유료 전환을 알게 된다는 현황과, 넣을 수 있는 자리 다섯 곳(스토어 설명, 첫 실행 팝업, 진입 전 고정 문구, 준비 화면 문구, 앱 밖 공지)을 제시. 이용권 결제 때 정한 "팝업·토스트 안 함"을 이번에도 유지할지 물음.
  - 최종: 업데이트 뒤 처음 한 번 뜨는 팝업을 넣는다. "팝업 안 함"은 반복해서 뜨는 안내에 대한 결정이었고, 이번은 한 번만 뜬다.
- 쟁점: 누구에게 띄우나
  - 처음 판단: "기존 사용자에게만 어떻게 띄울 수 있지?"
  - 바뀐 계기: AI 제안 — 폰에 남은 2.x 흔적(동의 기록, 로그인 세션, 마지막 로그인 수단)으로 고르는 방법과 서버 가입일로 고르는 방법, 각각 놓치는 사람(재설치·폰 교체 / 서버 필드 필요). 문구가 "그동안 무료로 써 주셔서 감사했어요"라 신규 가입자에게 뜨면 어색하다는 점.
  - 최종: 선택지 중 "폰에 2.x 흔적이 있는 사람". 앱을 다시 설치했거나 폰을 바꾼 기존 회원은 놓친다.
- 쟁점: 무엇을 말하나
  - 처음 판단: 처음 시안(무료 응시권 [N]회, 기간 무제한, 지난 기록 그대로 세 줄)에 대해 "서버비나 DB등으로 인해서 이용권 결제를 단행할 수 밖에 없었다는 내용도 넣어줘", 이어서 "1,2,3을 없애주고 저 안내만 남겨줘"
  - 바뀐 계기: "서버라는 말을 없애자 어차피 우리 ai도 쓰고 이것 저것 쓰니까". AI 제안 — "서버비·DB"는 일반 사용자에게 낯설어 "채점과 피드백, 기록 저장에 드는 비용"으로 바꿈. 세 줄 중 무료 횟수와 지난 기록은 확인 안 된 사실이었다.
  - 최종: 제목 "그동안 무료로 써 주셔서 감사했어요", 본문은 비용 이유 + 이번 업데이트부터 이용권이 있어야 한다는 문장. 비용 문장에 굵은 파스텔 밑줄을 넣었다가 구현 직전 "디자인에서 밑줄을 그냥 뺴줘"로 뺌.
- 쟁점: 어떻게 보이나
  - 처음 판단: 기존 토끼 마스코트 팝업 시안에 "저 토끼 없애고 다른 간단한 svg나 아이콘 이런 걸 통한 공지는 없을까? 여러가지 시안을 뽑아봐"
  - 바뀐 계기: AI 시안 6개 중 "3번이랑 5번을 합쳐서 3번 구조에 5번 멘트로 하면 안돼? 아이콘도 하트로 바뀐 걸 하나 더 만들어줘" → "8에 하트를 여기 저기 더 넣어서 불규칙하게" → 직접 만든 하트 안은 토끼 그림으로 하트를 빼고 넣음 → "그림이 더 많이 나오게 해줘 토끼 발 밑에도 배경이 나오게". AI 제안 — 제목에 "이용권"이 없어 제목만 보고 닫으면 놓칠 수 있음(그대로 감).
  - 최종: 시안 8번 — 카드 위쪽에 하트 토끼 그림(높이 300 기준), 아래에 왼쪽 정렬 제목·본문, "확인했어요"와 "이용권 살펴보기" 버튼.
- 쟁점: 구현 범위
  - 처음 판단: "이건 흐름이 간단하고 빠른 구현을 요구하는 거니까 바로 구현을 해줘 크게 결정할 사항은 없지?"
  - 바뀐 계기: AI 제안 — 대상 고르기 하나가 남았고, 동작이 바뀌어 3단계는 건너뛸 수 없다고 알림. 5단계는 생략을 고름.
  - 최종: 아래 구현 방식으로 3.0.0에 넣는다.
- 구현 방식(AI 제안): 앱이 켜질 때 한 번, 안내 상태가 저장돼 있지 않으면 동의 기록(`consent-record`, 2.x 첫 실행 동의 화면에서 저장, 탈퇴 때만 지움)이 있는지 보고 "띄울 차례" 또는 "해당 없음"을 저장한다. 3.0.0 신규 설치자는 동의 화면보다 이 판정이 먼저라 "해당 없음"이 된다. 홈 화면(회원만 옴)에서 "띄울 차례"면 팝업을 띄우고, 버튼을 누르면 "봤음"을 저장한다. "이용권 살펴보기"는 이용권 화면으로 간다. 그림은 용량을 줄여 넣고, 작은 화면에서는 그림 높이를 화면 높이에 맞춰 줄인다.
- 다룬 실패 범위: 3.0.0 신규 설치자에게 안 뜸, 같은 사람에게 두 번 안 뜸(저장 후), 작은 화면에서 버튼이 화면 밖으로 밀리지 않음, 2.x에서 로그아웃한 채 업데이트한 사람은 로그인 뒤 홈에서 뜸.
- 다루지 않은 것: 앱을 다시 설치했거나 폰을 바꾼 기존 회원(안 뜸), 2.x를 설치만 하고 동의 화면을 안 넘긴 사람(안 뜸), 탈퇴 후 같은 폰에서 다시 가입한 사람, 저장 실패 시 다음 실행에 한 번 더 뜰 수 있음, 무료 응시권 횟수 안내(서버 확인 전이라 뺌).
- 반증:모르겠다
