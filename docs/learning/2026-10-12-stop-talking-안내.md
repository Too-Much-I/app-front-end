# Stop Talking 안내

## 설계 논의
- 쟁점: 응답이 끝날 때마다 실제 시험처럼 "Stop Talking" 화면을 2초쯤 띄우려면 상태를 어떻게 둘까
  - 처음 판단: "상태를 compelete question이라고 해서 하나를 추가하면 되려나?"
  - 바뀐 계기: AI 제안 — 응답 종료 뒤 등록까지를 이미 `finalizing`이 맡고 있고, 시험 문구("저장되면 자동으로 넘어간다")도 그 구간과 같다. 새 phase 추가(A)와 `finalizing`을 최소 2초 유지(B)를 놓고, "녹음 저장이 실패하면 Stop Talking은 언제 사라져야 하나"를 따라가 보자고 했다.
  - 최종: "아 그러네 B로 하는게 맞겠다." `finalizing`에 들어간 시점부터 2초가 안 됐으면 등록 성공 뒤 남은 시간만 기다린다. 새 phase는 만들지 않는다.
- 쟁점: 안내 문구
  - 처음 판단: "해당 화면의 멘틀르 그대로 옮겨줘"
  - 최종: 시험 화면의 영어 문구를 번역하지 않고 그대로 쓴다.
- 쟁점: 안내 크기
  - 처음 판단: "팝업을 좀 더 크게 띄워도 될 것 같아 눈에 안들어와서"
  - 최종: 카드 폭을 넓히고 제목 `text-4xl`, 본문 `text-lg`로 키웠다.
- 다룬 실패 범위: 녹음 확정이나 등록이 실패하면 2초를 기다리지 않고 바로 복구 화면으로 간다. 안내는 헤더 아래 본문만 덮어서 시험 나가기 버튼은 계속 누를 수 있다.
- 다루지 않은 것: 2초를 기다리는 사이 시험을 나가도 기다림이 끝나면 답이 등록된다. 원래도 `recorder.finish` 동안 같은 틈이 있었고 이번에 최대 2초로 늘었다.
