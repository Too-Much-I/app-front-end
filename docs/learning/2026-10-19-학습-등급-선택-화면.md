# 학습 등급 선택 화면

## 설계 논의
- 쟁점: 학습에 들어가는 화면의 구성
  - 처음 판단: "원하는 목표 수준별로 학습 콘텐츠가 준비되어 있는 거니까 우리 앱 스타일 기반으로 해서 여러 가지 다지인 시안을 만들어줘"
  - 바뀐 계기: AI가 시안 A(등급 탭)·B(계단)·C(목표 고정 타일)·D(세트 피드)를 냈다. 사람: "탭을 바꿔서 진입할 수 있는게 제일 사용자 입장에서는 친숙하고 이해가 잘 될 것 같긴한데 너무 전형적인 디자인이라 그게 좀 걸려". AI 제안: 등급별 마스코트·좌우로 넘기는 카드·같은 문장을 등급별 길이로·퍼즐 모양 탭. 사람: "같은 문장을 다르게 보여주는 아이디어는 좋은 것 같은데 좌우로 넘기는 등급 카드는 어떻게 넘긴다는건지 잘 안그려져서" → AI가 넘기는 카드 시안(E)을 만들었다.
  - 최종: "저걸 같은 페이지 안에 다 넣는 것보다 저렇게 카드 형태로 목표 등급을 정하고 (문장을 보여주는 건 좋은 아이디어인 것 같아 이런 수준의 답변이 될 수 있게 응답을 한다는) 그 다음에 AL로 연습하기 그런 CTA를 누르면 거기서 파트를 결정하고 진입을 하는 걸로 하면 될 것 같아"
- 쟁점: 등급 카드 디자인과 캐릭터
  - 처음 판단: "이건 컬러 팔레트 카드인데 이렇게 이미지가 딱있고 그 밑에 예시가 검정 글씨로 들어간 디자인도 괜찮은 것 같아 이것도 하나의 선택지로 구현해줘"
  - 바뀐 계기: 사람: "카드2가 제일 맘에 드는데 CTA 버튼은 저 카드 색상이랑 일치 시켜주고 … 각 카드의 캐릭터는 달라야하는데(고양이, 새, 거북이) 지금 앱에서 한번도 안쓰는 이미지로 넣어줘" → AI가 웹의 `waiting_*` 그림과 파스텔 색으로 바꿨다. 사람: "지금 새로 만든 건 별로야 그 처음 만든 책위에 앉은 거북이랑 주황색 배경 괜찮았고 다른 카드 색상도 좋았어 … 공부와 연관된 이미지면 더 좋을 것 같아" → AI가 책 든 고양이·새 그림이 없어 책 더미를 깔았다. 사람: "책위에 인위적으로 쌓을 필요는 없고 거북이랑 크기를 맞춰줘". 공부 관련 그림을 고르면서 세 그림 모두 앱에서 이미 쓰는 그림이 됐고, "마지막 시안 그대로"로 답했다.
  - 최종: 팔레트 칩 카드. Easy 하늘(#80C8F0)·가방 멘 고양이, Medium 주황(#FC9351)·책 위 거북이, Hard 초록(#8ACB9C)·앉은 새. CTA는 가운데 카드 색.
- 쟁점: 카드에 보여 줄 예시 문장
  - 처음 판단: "저 문장은 샘플 데이터에 있던 값을 참고한 거니? 어차피 저 화면에 표현하는 건 목데이터를 그대로 쓸 것 같아서 물어보는 거야?"
  - 바뀐 계기: 시안 문장은 AI가 지어낸 것이었다. 목데이터(`85eb8df`의 `content.json`과 50건 일치)를 비교하니 16문항 중 6개가 세 등급 답이 같고, 나머지도 단어 몇 개 차이였다.
  - 최종: "목데이터에서 골라 고정". AI 제안: 세 등급 답이 모두 다르고 짧은 Part 3 Q6(지역 행사, `p3_reference_variant_100_q6`).
- 쟁점: 등급 이름
  - 처음 판단: "단계를 영어로 나누면 어느 정도 될까? basic hard 적절한 단어가 생각이 안나네 초보 중급 상급 이런 식으로"
  - 바뀐 계기: AI 제안: Beginner/Intermediate/Advanced, Basic/Standard/Advanced, Easy/Medium/Hard, Starter/Builder/Master, Steady/Strong/Fluent. 이후 사람이 팀과 다시 이야기했다.
  - 최종: "사용자가 체감할 수 있는 차이로 Easy Medium Hard로 구분해서 보여주기로 했어", "사용자한테 easy라고 보내주더라도 easy에 해당하는 파리미터는 value에 im3 이런 식으로 기존 파라미터를 일단 넣어줘"
- 쟁점: 진입 위치와 화면 사이 등급 전달
  - 처음 판단: "저게 화면 이동할 떄 파트 정해지는 화면에서도 레벨을 들고 있긴 해야하거든?"
  - 바뀐 계기: AI가 진입 위치(하단 탭·홈 카드·나중에)와 파트를 눌렀을 때(아무 일 없음·준비 중 안내·빈 학습 화면)를 물었다.
  - 최종: 하단 탭에 "학습" 추가. 등급 값(`IM3`·`IH`·`AL`)을 파트 화면에 route param으로 넘기고, 파트를 누르면 등급과 파트를 받는 빈 학습 화면으로 이동.
- 다룬 실패 범위: 첫 카드에서 왼쪽·마지막 카드에서 오른쪽으로 넘기기, 등급 없이 파트 화면에 들어가는 경우(route param 타입으로 막음), 화면 표시 이름과 서버 값이 어긋나는 경우(등급 값마다 표시 정보를 빠짐없이 묶음).
- 다루지 않은 것: 서버 호출(목록·진행률·채점)과 `LEARNING_RATE_LIMITED`, 고른 등급을 앱을 다시 켜도 기억하기, Part 1의 `common` 변환, 실제 학습 화면, iOS 기기 확인.
- 반증:카드를 변경했는데 CTA 버튼의 색상도 같이 변경이 되지 않는다면 실패로 보겠다.
