## 1. 주요 기능

**학습 흐름: 듣기 → 따라 말하기 → 실전 연습**

| 구분        | 구현 내용                                                                               |
| ----------- | --------------------------------------------------------------------------------------- |
| 학습 목록   | Part 1~5, IM·IH·AL 선택, 전체/완료 필터, 완료 카드 하단 정렬                            |
| 듣기        | 모범 음성 자동 재생, 문장 이동, 재생 위치에 따른 단어 강조                              |
| 따라 말하기 | 네이티브 STT, 인식 단어 표시, 빠진 단어 재인식, 70% 이상 인식 후 발화 종료 시 자동 진행 |
| 빈칸·힌트   | 전체 문장 → 일부 빈칸 → 전체 빈칸, 첫 글자·전체 문장 힌트, 수동 다음 이동               |
| 해석        | 질문·답변의 한글 뜻 보기                                                                |
| 실전 연습   | 답변 녹음, 내 답변 재생, 다시 녹음, 답변 제출                                           |
| 채점 결과   | 체크리스트별 충족 여부·피드백·전사문 표시, 학습 홈 이동                                 |
| 완료 기록   | 서버 저장, 등급별 완료 표시, 재진입 시 처음부터 시작                                    |
| 약점 훈련   | 준비 중 표시, 진입 비활성                                                               |

### 파트별 차이

| 파트   | 문제 자료       | 따라 말하기                  | 실전 종료                         |
| ------ | --------------- | ---------------------------- | --------------------------------- |
| Part 1 | 지문            | 보면서 읽기만 지원           | 내 녹음·모범 음성 비교, 채점 없음 |
| Part 2 | 사진            | 전체 → 일부 빈칸 → 전체 빈칸 | 체크리스트 채점                   |
| Part 3 | Q5·6·7 질문     | 문항별 빈칸 3단계            | 문항별 체크리스트 채점            |
| Part 4 | Q8·9·10 질문·표 | 문항별 빈칸 3단계            | 문항별 체크리스트 채점            |
| Part 5 | 의견 질문       | 전체 → 일부 빈칸 → 전체 빈칸 | 체크리스트 채점                   |

- Part 1: 등급 선택·빈칸·해석 제외, 실전 녹음 업로드 없음
- Part 4: 질문에 필요한 표 발췌 표시, 전체 표 별도 확인
- Part 3·4: 카드당 3문항, 전체 문항 완료 시 카드 완료 처리
- 등급 값: 화면 `IM` = API `IM3`, Part 1 = `common`
- 채점 기준: 내용 체크리스트 충족 여부, 공식 토익스피킹 점수·발음 점수 제외
- 저장 범위: 완료 기록만 서버 저장, 중간 문장·빈칸 단계 저장 없음

## 3. 서버 연동

```text
목록·상세 조회 → 백엔드 → MongoDB 콘텐츠·완료 기록 / S3 사진·음성
따라 말하기   → 기기 내 STT
실전 제출     → 제출 생성 → S3 업로드 → 채점 요청 → 결과 조회 → 완료 저장
```

- API: 기존 Learning Core 주소의 `/api/v1/learning/*` 10개
- 인증: 기존 앱의 Bearer 토큰 사용, S3 업로드에는 Bearer 제외
- 데이터: 문제·답안·체크리스트는 MongoDB, 사진·음성·제출 녹음은 S3
- 채점: 백엔드/Lambda의 STT·체크리스트 판단, 프론트의 모델 직접 호출 없음
- 재시도: 동일 녹음의 제출 ID 재사용, ‘대기 중단’은 결과 조회만 중단
- 키 관리: AWS·MongoDB·모델 키의 프론트 전달 불필요
